# Evaluasi Pekan 6 - Kedai Senja

Sistem manajemen pencatatan data pemesanan, pembersihan teks, mesin kasir otomatis dengan rincian kembalian pecahan, laporan harian, latihan logika, serta eksperimen JavaScript.

## Cara Menjalankan
1. Clone repositori ini ke komputer lokal.
2. Buka file HTML sesuai modul yang ingin dijalankan (`index.html`, `logika.html`, `perbaikan.html`, atau `eksperimen.html`) di browser web atau Live Server.
3. Buka Console Browser (F12) untuk melihat hasil eksekusi program secara interaktif.

## Teknologi yang Digunakan

- JavaScript (ES6+)
- Git & GitHub
